# 🧠 Memory Card Game

A simple and fun browser-based **Memory Card Game** where players match pairs of Pokémon energy cards. Built using HTML, CSS, and JavaScript.

---

## 🚀 Features

- 🎴 **Dynamic Card Generation** – All cards are loaded and shuffled dynamically using JavaScript.
- 🔄 **Card Flipping Logic** – Click to reveal cards; unmatched cards flip back after a short delay.
- ❌ **Mistake Counter** – Tracks your incorrect guesses in real time.
- 🏆 **Win Condition** – Displays a "You Won!" message once all pairs are matched.
- 🔁 **Restart Button** – Reloads the board with freshly shuffled cards.

---

## 🛠 Tech Stack

- **HTML** – Structure of the game board and elements.
- **CSS** – Styling the cards and layout.
- **JavaScript** – Game logic, DOM manipulation, shuffling, and event handling.
